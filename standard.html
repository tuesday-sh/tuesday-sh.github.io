The SureThingNet Standard

Enterprise networking has decades of battle-tested standards—the OSI model, CISA asset inventories, NSA home segmentation guidelines, and NIST CM-8 / CSF. Home networks got none of it. The SureThingNet Standard distills those practices into four plain-English ordinal scales built into every screen of Tuesday.sh—and the foundation for our upcoming SureThingNet Home companion app.

Scale C: The 8 Hardware Categories (C1 → C8)

Every device on your network belongs to one of eight ordered hardware categories—from the internet gateway at the edge down to guest devices. No phantom switch ports, no arbitrary folders.

Gateway / WAN
C1 • L3
Home label: Wi-Fi Router / Gateway — Perimeter firewall, WAN uplink, NAT, DHCP server, and default gateway.
UDM-Pro, UXG-Pro, Firewalla, pfSense
Switch Backbone
C2 • L2
Home label: Wired Switch Hub — Physical distribution plane, 802.1Q VLAN trunking, and PoE power delivery.
USW-24-PoE, Enterprise 8 PoE, Catalyst
Wireless AP
C3 • L1/2
Home label: Wi-Fi Access Point — Radio-frequency access point translating wireless airwaves into wired Ethernet.
U6-Pro, U7-Pro, Netgear AP, Eero
Compute / Server
C4 • L4–7
Home label: Home Server & Storage — Storage (NAS), local DNS, container virtualization, and homelab workloads.
TrueNAS, Unraid, Proxmox VE, Synology
Vision / Camera
C5 • L7
Home label: Smart Camera — Surveillance video, real-time RTSP/WebRTC streams, and perimeter sensing.
UniFi Protect G5, Owlet Cam, Reolink
Smart Home / IoT
C6 • L7
Home label: Smart Home Hub — Home automation controllers, networked printers, and constrained smart peripherals.
Home Assistant, Hubitat, Hue, Ecobee, Printers
Workstation / Client
C7 • L7
Home label: Personal Computer / Phone — Primary trusted user devices carrying user identities, keys, and productivity data.
MacBook Pro, ThinkPad, Linux PC, iPad
Guest / Human (L8)
C8 • L8
Home label: Guest / Visitor Device — Isolated perimeter for ephemeral human visitors, guest Wi-Fi, and user policy.
Guest Portal, Visitor Laptop, Cast Client

Scale S: The 7-Step Vertical Stack (S0 Space → S6 Apps)

Orders every device inspector from physical outlet to running software—and powers root-cause troubleshooting: if S0 Power or S2 Switch Port fails, downstream S6 App alerts are noise.

S0
Rack, Room & Power
Room & Outlet — Where the device physically lives and how it receives power.
S1
Hardware & Lifespan
Device & Warranty — Model identity, manufacturer support window, and End-of-Life tier.
S2
Port, Speed & PoE
Cable & Wi-Fi Signal — Physical uplink, link speed, or upstream switch jack.
S3
VLAN, IP & Firewall
Network Lane — Which trust ring the device sits in and how it is isolated.
S4
Firmware
Built-in Software — Bootloader, BIOS/UEFI, and over-the-air vendor firmware releases.
S5
OS, Kernel & Runtime
System Software — Host operating system, hypervisor, and container runtime.
S6
Packages & Services
Apps & Features — Exposed ports, running daemons, and Package URLs (PURLs).

Scale Z: The 6 Inside-Out Trust Rings (Z0 Core → Z5 Internet)

Derived from CISA OT Asset Inventory and NSA Home Network Best Practices. Lower rings can initiate connections outward to higher rings, never backward—like keeping a guest bedroom separate from your home office safe.

Z0
Core Gear (VLAN 1)
Wi-Fi & Network Gear — Routers, switches, and wireless access points.
Z1
Trusted (VLAN 10)
Main Home Wi-Fi — Family laptops, phones, and primary workstations.
Z2
Homelab (VLAN 20)
Home Storage & Media — TrueNAS, Unraid, Proxmox, and self-hosted services.
Z3
Smart Home (VLAN 30)
Smart Home Lane — TVs, security cameras, thermostats, smart plugs, and IoT hubs.
Z4
Guest (VLAN 99)
Guest Wi-Fi — Client-isolated visitor access with internet only.
Z5
Internet Uplink (WAN)
Internet Doorway — Public ISP modem, fiber ONT, and WAN boundary.

Scale R: The 4 Operational Rhythms (R1 Event → R4 Annual)

Aligned with NIST CM-8 (System Component Inventory) and the NIST Cybersecurity Framework—without enterprise ITIL overhead. Four predictable habits keep a home network healthy.

R1
Plug & Tag (NIST CM-8)
Name New Device — Capture what you know right when a new box joins the network, even as a rough guess.
R2
Monthly Patch Tuesday Readiness
Monthly CVE/KEV & Firmware Triage — Review matched security advisories on the 2nd Tuesday of each month.
R3
Seasonal Safety, Passwords & Drift Audit
Seasonal Check-Up — Every 90 days, confirm rough device guesses, check CPSC recalls, and clear stale gear.
R4
Annual Gear Review
Yearly Lifespan Check — Review warranties, End-of-Life timelines, and plan replacements before hardware fails.

The OSI 7+1 Layer Reference Model (L8 Human → L1 Physical)

Classic networking stops at Layer 7. Home security actually starts at Layer 8—the humans who own, share, and maintain the network.

LAYER 8
The Human Layer (Users • Admins • Policy)
Human approval workflows, advisory mute overrides, household expectations, and seasonal audit accountability.
LAYER 7
Application (HTTP • DNS • RTSP • MQTT)
Smart cameras (C5), IoT bridges (C6), Home Assistant, and application-level CVEs.
LAYER 6
Presentation (TLS/SSL • JSON • Encryption)
Device TLS certificates, local JSON backups, and cryptographic firmware handshakes.
LAYER 5
Session (RPC • Sockets • WebRTC)
Persistent camera streams and remote management sessions.
LAYER 4
Transport (TCP • UDP • Port Numbers)
Homelab servers (C4) listening on service ports (443, 80, 53).
LAYER 3
Network (IP Routing • Subnets • NAT)
Core Gateways (C1: UDM-Pro / UXG / Firewalla) and VLAN routing boundaries.
LAYER 2
Data Link (MAC Frames • Switches • 802.1Q)
Switch Backbone (C2) and the 16×8 LED matrix chassis (128 slots).
LAYER 1
Physical (Cat6 Copper • Fiber SFP+ • RF)
Wireless Access Points (C3), Ethernet runs, and physical RJ45 switch jacks.
